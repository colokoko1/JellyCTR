# JellyCTR
A Jellyfin client for the 3DS.
---
**Music only for the time being**
## Development status
Moved to discussions.

## Features:
* Support for all formats that Jellyfin is capable of transcoding
* Semi-polished UI
* Lossless audio streaming
* Compatible with all 3DS models
* Seamless setup
## Limitations:
* No video support
* No lyric support
* Layout needs improvement
* Stuttering on slow networks
